# alexhandymanorlando.com

Website for **Alex Handyman & Smart Home** (Orlando, FL).

Static site (HTML + CSS + JS, no build step), deployed on Vercel.

- `index.html` – the whole page
- `favicon.svg`, `og-image.png` – icons and social share image
- `robots.txt`, `sitemap.xml` – SEO
- `vercel.json` – Vercel settings

Edit `index.html`, commit to `main`, and Vercel redeploys automatically.
